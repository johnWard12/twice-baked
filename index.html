Twice Baked

A co-op cooking game for iPhone. Chop, cook, plate, serve and wash up before the orders run out, on your own or with a friend.

Contact

Questions, bugs or ideas: SmTownGamesBusiness@gmail.com

Cooking with a friend online

One player taps Cook Together → Open a Kitchen and reads out the code. The other taps Cook Together, types the code in and taps Join. Both phones need an internet connection, but they don't have to be on the same network.

Cooking on the same Wi-Fi

One player taps Cook Together → Host here, and the other types the address it shows and taps Join. When iPhone asks to find devices on your local network, both players tap Allow. If someone tapped Don't Allow, turn it back on in Settings → Privacy & Security → Local Network → Twice Baked.

"Your two games are different versions"

Both phones need the same version of Twice Baked. Update the game on both phones, then try again.
